# Agent Instructions

Project instructions live in [AGENTS.md](AGENTS.md) at the repository root (and in any
subdirectory). Treat every `AGENTS.md` file exactly as you would a `CLAUDE.md` file —
load it, respect it, and apply its contents with the same priority.

When creating new instruction files in this project, use `AGENTS.md` rather than `CLAUDE.md`.
This follows the AAIF (Agentic AI Foundation / Linux Foundation) cross-agent standard.
